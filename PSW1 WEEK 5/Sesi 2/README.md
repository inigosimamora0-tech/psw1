1. Starter Katalog

Pada tahap ini, saya menggabungkan file index.html dari Week 1 dan Week 2 menjadi satu halaman utama. Selain itu, saya memastikan bahwa file CSS dan JavaScript tetap terhubung serta berjalan sesuai fungsinya.

Hasil Aktual:
Halaman web dapat dijalankan dengan baik. Tampilan yang diatur oleh CSS dan fungsi yang diatur oleh JavaScriptsesuai dengan yang diharapkan.

2. Navigasi Fleksibel

Saya menambahkan beberapa aturan CSS untuk mengatur tata letak bagian Kegiatan dan Kontak. Pengaturan padding dilakukan agar kedua bagian dapat berada dalam satu baris serta mengurangi jarak yang terlalu jauh antar elemen.

Hasil Aktual:
Bagian Kegiatan dan Kontak berhasil ditampilkan dalam satu baris dengan jarak yang lebih rapi dan proporsional.

3. Card Fleksibel

Saya menambahkan CSS untuk membuat tampilan kotak pada bagian kegiatan mahasiswa. Selain itu, ukuran card yang sebelumnya lebih besar saya sesuaikan agar lebih kecil dan rapi. Saya juga menambahkan satu elemen <article> baru pada HTML sehingga jumlah card bertambah dari tiga menjadi empat.

Hasil Aktual:
Setiap kegiatan ditampilkan dalam bentuk card yang lebih proporsional, dan seluruh card tersusun dengan rapi.

4. Konten Panjang dan Pengukuran

Saya menambahkan properti overflow pada bagian judul (h2) untuk menangani teks yang terlalu panjang. Dengan pengaturan ini, teks tidak keluar dari batas card dan tetap tersusun ke bawah secara rapi.

Hasil Aktual:
Saat diuji menggunakan judul yang panjang, teks tetap berada di dalam card dan tampil dengan struktur yang rapi tanpa merusak tampilan halaman.
