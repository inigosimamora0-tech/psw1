Refleksi fungsi HTML, CSS, dan Javascript
1. HTML
HTML (HyperText Markup Language) dapat dianggap sebagai kerangka utama sebuah halaman website. HTML menentukan elemen apa saja yang terdapat di dalam halaman, mulai dari judul, paragraf, gambar, tautan, tabel, formulir, hingga tombol.
Tanpa HTML, Web tidak memiliki struktur yang jelas. Karenanya HTML dapat digunakan untuk menentukan judul, nama pengguna, deskripsi, foto, tombol dan tautan. Kekurangannya, htmHTML itu sangat sederhana dan tidak memiliki visual yang menarik

2. CSS
CSS atau Cascading Style Sheets bertugas mengatur bagaimana elemen HTML ditampilkan. Warna, ukuran tulisan, jarak antarbagian, posisi elemen, bentuk tombol, hingga tampilan responsif dapat diatur menggunakan CSS.
Dengan CSS, halaman yang awalnya hanya berisi teks dan elemen dasar dapat berubah menjadi tampilan website yang lebih modern dan nyaman digunakan. Jelasnya, fungsi dari CSS adalah untuk mengatur warna dan ukuran tertentu, sudut yang membulat, efek ketika kursor diarahkan ke tombol, posisi yang lebih rapi
tampilan yang menyesuaikan layar perangkat
Namun dengan ini pun CSS masih belum punya kekurangan, yaitu pengguna masih kurang dapat berinteraksi dwngan isinya.

3. Javascript
Javascript adalah buah ceri di atas kue. Dengan HTM sebagai struktur yang membentuk web, CSS sebagai pakaiannya, maka Javascript datang sebagai otaknya.
JavaScript merupakan bahasa pemrograman yang memungkinkan website memberikan respons terhadap tindakan pengguna. Ketika pengguna mengklik tombol, mengisi formulir, membuka menu, mengganti pilihan, atau melakukan aktivitas tertentu, JavaScript dapat digunakan untuk menentukan apa yang harus terjadi.
