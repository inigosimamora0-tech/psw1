1. Saya mencoba untuk mengganti nama file tautan yang ada di index dengan file yang lain, maka destinasi tautan akan tidak sesuai, atau bahkan tidak valid bila kita memasukkan id yang sembarangan.
2. Jika saya tidak memasukkan alt pada img di tampilan laman saya gambar nya tidak akan muncul.
3. Jika tabel tidak memiliki maka tabel itu sendiri kehilangan judulnya. Judul menunjukkan label dari tabel tersebut, fungsi/kegunaan tabel itu di sana apa.
4. Jika title halaman yang satu sama dengan title halaman yang lain, maka ketika halaman itu diklik maka kita sama saja kembali lagi ke halaman yang sama.
 
 Refleksi
 1. Dalam mempelajari HTML dan pengembangan web, saya memahami bahwa tautan relatif dan tautan absolut memiliki fungsi yang berbeda. Tautan relatif digunakan untuk menghubungkan halaman atau file yang masih berada dalam satu proyek atau direktori yang sama, sehingga lebih fleksibel ketika website dipindahkan ke server lain. Sementara itu, tautan absolut menggunakan alamat lengkap (URL) yang mengarah ke lokasi tertentu di internet. Dari sini saya belajar pentingnya memilih jenis tautan sesuai kebutuhan agar navigasi website dapat berjalan dengan baik.

3. Saya juga mempelajari penggunaan atribut alt pada gambar. Atribut alt berfungsi untuk memberikan deskripsi gambar, terutama untuk pengguna pembaca layar dan ketika gambar gagal dimuat. Oleh karena itu, alt harus diisi ketika gambar mengandung informasi penting atau mendukung isi konten. Namun, jika gambar hanya bersifat dekoratif dan tidak menambah informasi, alt boleh dikosongkan (alt="") agar tidak mengganggu pengalaman pengguna yang menggunakan teknologi bantu. Hal ini membuat saya sadar bahwa aksesibilitas adalah bagian penting dalam pembuatan website.

3. Selain itu, saya memahami alasan mengapa tabel tidak digunakan untuk layout halaman. Dahulu tabel sering dipakai untuk mengatur tata letak, tetapi cara tersebut membuat struktur kode menjadi rumit, sulit dipelihara, dan kurang ramah bagi aksesibilitas. Saat ini, CSS dengan teknik seperti Flexbox dan Grid menjadi solusi yang lebih tepat karena mampu memisahkan struktur konten dari tampilan. Dengan menggunakan CSS, halaman menjadi lebih responsif, mudah dikembangkan, dan sesuai dengan standar web modern.

Dari ketiga materi tersebut, saya menyadari bahwa pembuatan website tidak hanya berfokus pada tampilan, tetapi juga pada efisiensi, kemudahan pemeliharaan, dan aksesibilitas bagi semua pengguna. Pemahaman ini membantu saya menjadi lebih teliti dalam membangun halaman web yang baik dan sesuai standar.
